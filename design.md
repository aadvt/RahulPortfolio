# DESIGN SYSTEM / CREATIVE DIRECTION

## OVERALL CREATIVE DIRECTION

The visual identity should feel:

- Experimental
- Youth-driven
- Streetwear-inspired
- Editorial
- Slightly chaotic but intentional
- Modern brutalist + graffiti fusion
- High contrast
- Bold typography focused
- Visually loud but structurally organized

The design language combines:
- Graffiti aesthetics
- Swiss/grid layouts
- Streetwear branding
- Y2K editorial composition
- Underground poster culture
- Urban fashion campaign visuals
- Creative portfolio layouts

The overall vibe should feel like:
- a fashion editorial,
- a Behance branding project,
- a Gen-Z creative portfolio,
- and a premium underground clothing brand
all combined together.

---

# VISUAL STYLE PRINCIPLES

## 1. TYPOGRAPHY-FIRST DESIGN

Typography is the main visual element.

Text should not just communicate information —
it should BE the design itself.

Use:
- Oversized headings
- Experimental letterforms
- Distorted typography
- Layered text
- Graffiti-inspired fonts
- Bold geometric sans-serifs
- Handwritten marker styles
- Sharp contrast between clean + messy fonts

The typography should feel:
- aggressive
- energetic
- expressive
- rebellious
- fashionable

---

# TYPOGRAPHY SYSTEM

## PRIMARY FONT STYLE

Use bold geometric sans-serif fonts similar to:

- Monument Extended
- Clash Display
- Druk
- Anton
- Integral CF
- Helvetica Now Display Black
- Archivo Black
- Satoshi Black

Characteristics:
- Thick
- Wide
- Heavy
- Compact spacing
- Strong silhouettes

---

## SECONDARY FONT STYLE

Use handwritten / graffiti / brush fonts for accents.

Characteristics:
- Imperfect
- Organic
- Fast strokes
- Street-inspired
- Chaotic but readable

Use these ONLY as accents:
- signatures
- overlays
- highlights
- decorative words
- motion elements

Do NOT overuse them.

---

## TYPOGRAPHY COMPOSITION RULES

### Important:
Typography should overlap.

Examples:
- giant heading behind images
- text partially cut off
- letters intersecting shapes
- handwritten text on top of clean typography
- mixed scales
- rotated text
- compressed layouts

Text should feel alive.

Avoid:
- centered boring layouts
- excessive whitespace
- corporate spacing

# COLOR SYSTEM

## PRIMARY COLORS

Base palette:

### Black
Use as dominant background.

HEX:
#000000

### White
Main typography and contrast color.

HEX:
#FFFFFF

### Red Accent
Used for energy and attention.

HEX:
#FC5050
or
#E3142A

### Yellow Accent
Used sparingly for highlights.

HEX:
#F7D000

---

## COLOR USAGE RULES

### 80% monochrome
Most of the design should stay:
- black
- white
- grayscale

### 20% accent colors
Use red or yellow only for:
- highlights
- stars
- shapes
- stickers
- underlines
- focus elements

Accent colors should POP aggressively.

---

# LAYOUT SYSTEM

## GRID STRUCTURE

Use structured editorial grids.

Preferred:
- 12-column layout
- asymmetrical composition
- overlapping sections
- broken alignment intentionally

The design should feel:
organized chaos.

---

# SPACING STYLE

Avoid overly clean spacing.

Instead:
- tight compositions
- layered sections
- overlapping objects
- compressed typography
- floating graphic elements

But maintain readability.

---

# BACKGROUND STYLE

Primary backgrounds:
- matte black
- off-white
- textured grayscale

Add subtle:
- grain
- paper texture
- noise
- scan lines
- print imperfections

The background should NEVER feel flat.

---

# GRAPHIC ELEMENTS

Use decorative graphics heavily.

Examples:
- stars
- scribbles
- rings
- barcode elements
- stickers
- arrows
- crosses
- flames
- hand-drawn symbols
- circles
- distorted shapes
- abstract marks

These elements should:
- feel spontaneous
- look layered
- create movement

Do NOT make them too clean/vector-perfect.
